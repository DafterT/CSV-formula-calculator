# CSV Formula Calculator

Небольшой CSV-калькулятор на C11. Программа читает CSV-таблицу, вычисляет ячейки с формулами и печатает итоговую таблицу в stdout.

## Возможности

- Чтение CSV без кавычек и экранирования.
- Поддержка целых чисел `int64_t`.
- Формулы вида `=ARG1OPARG2`, где аргумент это число или ссылка на ячейку.
- Операции: `+`, `-`, `*`, `/`.
- Ссылки вида `A1`, `B2`, `Cell30`.
- Обработка зависимостей между формулами.
- Ошибки для циклов, неизвестных ссылок, деления на ноль и переполнения.

## Сборка

Нужны Linux или WSL, CMake 3.16+ и `gcc` или `clang`.

```bash
cmake -S . -B build
cmake --build build
```

На Windows через WSL:

```powershell
wsl.exe sh -lc "cmake -S . -B build && cmake --build build && ctest --test-dir build --output-on-failure"
```

## Запуск

```bash
./build/csvreader file.csv
```

Пример входа:

```csv
,A,B,Cell
1,1,0,1
2,2,=A1+Cell30,0
30,0,=B1+A1,5
```

Вывод:

```csv
,A,B,Cell
1,1,0,1
2,2,6,0
30,0,1,5
```

## Формат CSV

- Первая строка: пустая первая ячейка, затем имена колонок.
- Имя колонки: латинские буквы и `_`.
- Первый столбец строки данных: положительный номер строки.
- Номера строк могут идти в любом порядке; вывод сохраняет входной порядок.
- Ячейка: число или формула.
- Поддерживаются `\n` и `\r\n`; одиночный `\r` считается ошибкой.
- Пустые ячейки, дубли строк/колонок и разная ширина строк запрещены.

## Формулы

Формула не содержит пробелов:

```text
=ARG1OPARG2
```

Примеры:

```text
=A1+Cell30
=B1+A1
=10*A2
=A1/2
=A1--2
```

Числа могут быть отрицательными, но `+10` как число не допускается.

## Ошибки

При ошибке программа пишет в stderr:

```text
error: <message>
```

Код возврата ненулевой.

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

Тестовые бинарники: `csv_parser_tests`, `formula_parser_tests`, `evaluator_tests`.
